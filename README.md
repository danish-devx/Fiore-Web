🌸 Fiore – Perfume Brand Website

Fiore is a premium, modern & fully responsive perfume brand website UI designed for fragrance, beauty, and lifestyle brands.

Built with a clean layout, smooth responsiveness, and elegant visuals to deliver a luxury brand feel.

✨ Features

Fully responsive design (Mobile, Tablet & Desktop)

Modern UI with premium perfume aesthetics

Product showcase & featured collections

Testimonials carousel

Blog / News section

Brand logos & advertisement section

Clean footer with newsletter & social icons
